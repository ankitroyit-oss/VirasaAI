2. AI Heritage Recognition — Complete Flow

End-to-end flow from camera input to cultural data display

flowchart TD
    START(["User Opens AI Scanner"]) --> CHOICE{"Choose Input Method"}
    CHOICE -->|Camera| CAM["Request Camera Permission"]
    CHOICE -->|Upload| UPLOAD["Select Photo from Gallery"]
    CHOICE -->|Demo| DEMO["Load Demo Mode"]
    CAM --> PERMIT{"Permission Granted?"}
    PERMIT -->|Yes| STREAM["Start Video Stream"]
    PERMIT -->|No| FALLBACK["Show Error - Suggest Upload"]
    FALLBACK --> UPLOAD
    STREAM --> CAPTURE["Capture Frame to Canvas"]
    UPLOAD --> CANVAS["Draw Image to Canvas"]
    DEMO --> SKIP["Use Pre-selected Site"]
    CAPTURE --> PREPROCESS["Preprocess Image 224x224"]
    CANVAS --> PREPROCESS
    PREPROCESS --> TFJS["TensorFlow.js Inference"]
    TFJS --> MATCH["Match to Heritage DB"]
    MATCH --> RESULT["Site Identified"]
    SKIP --> RESULT
    RESULT --> CARD["Display Result Card"]
    CARD --> TABS{"Explore Tabs"}
    TABS --> T1["History"]
    TABS --> T2["Cuisine"]
    TABS --> T3["Art and Craft"]
    TABS --> T4["Stories"]
    TABS --> T5["Fun Facts"]

7. AI + Database — Sequence Diagram

Step-by-step sequence of how AI identification triggers cultural data retrieval

sequenceDiagram
    actor User
    participant Camera
    participant Canvas
    participant TF as TensorFlow.js
    participant Model as MobileNet
    participant DB as Heritage DB
    participant UI as Result UI
    User->>Camera: Point at heritage site
    Camera->>Canvas: Capture frame
    Canvas->>TF: Send preprocessed image
    TF->>Model: Run classification
    Model-->>TF: Predictions + Confidence
    TF->>DB: Match Site ID
    DB-->>UI: Full cultural data
    Note over UI: History, Architecture, Cuisine, Art, Stories, Fun Facts
    UI-->>User: Display result card with tabs
