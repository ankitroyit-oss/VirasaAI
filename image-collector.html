🖼️ Image Collector — Training Data for VirasaAI

Click the search links below to find and download training images for each heritage site

📋 How to Collect Images

  1. Step 1 Click a search link below for any heritage site
  2. Step 2 On Google Images, right-click → "Save Image As" to download (or use a bulk downloader extension)
  3. Step 3 Save 50-100 images per site into separate folders (e.g., taj-mahal/, red-fort/)
  4. Step 4 Include different angles, lighting, distances, and weather conditions
  5. Step 5 Go to Teachable Machine and upload each folder as a class

💡 Tip: Use the Chrome extension "Download All Images" to bulk-download from Google Images pages
